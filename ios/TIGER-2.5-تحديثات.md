# TIGER IPTV — تحديث 2.5

## 1) اللوقو الرسمي
- تم استبدال شعار الأسد القديم بالشعار الرسمي الذي أرسلته: رأس النمر بالخطوط البرتقالية (بروفايل متجه لليسار).
- الشعار الآن مطابق تماماً للأصل، بدون أي تغيير في الرسم أو النسب.
- تم تحديثه في مكانين:
  - داخل التطبيق: `Assets.xcassets/LionMark.imageset/lion_mark.png` (نسخة شفافة تُلوَّن تلقائياً بلون الهوية).
  - أيقونة التطبيق: كل مقاسات `AppIcon` (الافتراضي / الداكن / الفاتح / الذهبي) من نفس الصورة الأصلية على خلفية سوداء.

## 2) وضوح النصوص
- كانت النصوص تُستخدم بلون `TigerTheme.ink` الداكن فوق خلفية داكنة، فكانت غير مقروءة.
- تم تحويل كل النصوص في شاشة الترحيب وإعدادات المظهر إلى الأبيض / أبيض بشفافية 72% لتبقى واضحة في الوضعين الداكن والفاتح.

## 3) شاشة الترحيب (Onboarding)
- أعيد ترتيبها في 5 صفحات: الترحيب، المزايا، **حزمة 200+ ميزة** (جديدة)، المظهر، جاهز.
- تصميم أنظف: مسافات موحّدة، بطاقات زجاجية، أزرار برتقالية متدرجة، نقاط تنقّل متحركة.

## 4) حزمة 200 ميزة جديدة
- `Features/FeaturePack200/TigerFeatureCatalog.swift`: كتالوج من **200 ميزة** موزّعة على 15 قسماً (التشغيل، البث المباشر، الأفلام، المسلسلات، الاكتشاف، الصوت، الترجمة، التنزيلات، الشبكة، الخصوصية، الإتاحة، التخصيص، المشاركة، التشخيص، الطاقة).
- `TigerFeatureFlags`: حالة تشغيل/إيقاف لكل ميزة محفوظة في UserDefaults (`tiger.features.enabled.v200`) مع تفعيل الكل / إعادة الضبط / تعطيل الكل.
- `FeatureCenterView`: مركز مزايا كامل بالعربية — بحث، تصفية بالأقسام، "المفعّلة فقط"، حلقة تقدّم، وورقة تفاصيل لكل ميزة.

## 5) أدوات سريعة داخل البث والأفلام والمسلسلات
- `TigerQuickToolsStrip` يُضاف أعلى كل من: البث المباشر، الأفلام، المسلسلات.
- 8 أدوات عملية تعمل فعلياً:
  1. **مؤقت النوم** (15–120 دقيقة + عدّاد تنازلي).
  2. **سرعة التشغيل الافتراضية** (0.5x–2.0x).
  3. **نسبة العرض** (ملائم/تعبئة/تمديد/16:9/4:3).
  4. **مزامنة الترجمة** (−5 إلى +5 ثانية).
  5. **اختبار سرعة الشبكة** (زمن استجابة + Mbps).
  6. **تنظيف التخزين** (كاش + ملفات مؤقتة).
  7. **المظهر السريع** (داكن/فاتح/تلقائي + 6 ألوان).
  8. **بيانات الجهاز** (الإصدار، البناء، الموديل، النظام، المساحة، اللغة).
- زر "200+ ميزة" داخل الشريط ينقلك مباشرة إلى مركز المزايا.

## 6) نقاط الدخول
- قائمة النافبار (⋯) في لوحة التحكم: عنصر جديد "مركز المزايا (200+)".
- إعدادات → قسم جديد "المزايا".

## 7) بنرات المحتوى وترتيب الأقسام (تحديث جديد)
- ملف جديد: `Features/FeaturePack200/ContentBanners.swift` يحتوي مكوّنات قابلة لإعادة الاستخدام:
  1. **بانر "فلم اليوم" / "مسلسل اليوم"** — اختيار يومي ثابت (`TigerDailyPick`) يتغيّر تلقائياً كل يوم، مع صورة خلفية سينمائية، تقييم، نبذة، وزر مشاهدة.
  2. **زر "مفاجئني" (النرد)** — يفتح تفاصيل عمل عشوائي من مكتبتك فوراً.
  3. **بطاقات مجموعات** — أفضل الأفلام / أحدث الإضافات / كل الأفلام (ونفسها للمسلسلات) ببنرات ملوّنة وأعداد مباشرة.
  4. **تصفّح سريع (Chips)** — تصنيفات مستخرجة من أسماء الأقسام، والضغط عليها ينقلك مباشرة للقسم المطابق.
  5. **رف "أفضل الأفلام / أفضل المسلسلات"** — الأعلى تقييماً مع أرقام ترتيب (1، 2، 3…).
  6. **رف "الأكثر مشاهدة"** — يُحسب من سجل المشاهدة الفعلي (`DBWatchHistory`) مع أرقام ترتيب.
  7. **شاشات مجموعة كاملة** — عرض كل عناصر أي رف في شبكة مع بحث.
- **ترتيب جديد لتبويب الأفلام:** الإحصاءات → الأدوات السريعة → فلم اليوم → اختيار المحرر → متابعة المشاهدة → بطاقات المجموعات → تصفّح سريع → أفضل الأفلام → الأكثر مشاهدة → أحدث الإضافات → كل الأقسام.
- **ترتيب جديد لتبويب المسلسلات:** الإحصاءات (جديد) → الأدوات السريعة → مسلسل اليوم → اختيار المحرر → متابعة المشاهدة → بطاقات المجموعات → تصفّح سريع → أفضل المسلسلات → الأكثر مشاهدة → أحدث الإضافات → كل الأقسام.
- **تبويب البث المباشر:** شريط "انتقل سريعاً لقسم" للتنقل الفوري بين أقسام القنوات.
- كل المكوّنات تحترم إخفاء الأقسام، البحث، و`TigerFeatureFlags` (متابعة المشاهدة تختفي عند تفعيل ميزة الإخفاء #57).
